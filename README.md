# Weather Lens

A mobile-first, installable weather dashboard designed for quick decisions on rain and damaging wind.

- Works in Safari / Chrome / Firefox as a normal webpage.
- Can be added to an iPhone/iPad home screen as a PWA.
- Search or device location.
- Hourly temperature, rain probability/amount, sustained wind, gusts and humidity.
- Impact-oriented gust emphasis.
- Uses Open-Meteo by default; Meteoblue key storage is prepared for an exact Meteoblue adapter.

The Meteoblue API key is never committed: if entered in the UI it is stored only in the browser's localStorage.
