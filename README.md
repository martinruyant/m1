# Legend Builder

A personalized reflex game you can run locally in any browser.

## Play now

From this folder:

```bash
./start-game.sh
```

Then open:

- http://localhost:4173

Press `Ctrl+C` in the terminal when you're done.

## Controls

- Fill in your profile and click **Start my legend**.
- Click the glowing target as quickly as possible.
- Avoid clicking outside the target or your combo resets.
- Golden targets appear periodically and award bonus points.

## Manual start (alternative)

```bash
python3 -m http.server 4173
```
